Plain-English words used on this page
  • API — the way one piece of software asks another for data. If an app has a public API, an assistant can read or change things in it.
  • MCP — a standard plug for AI assistants. If an app already has an official MCP server, assistants can connect to it without custom work.
  • Self-serve — you can sign up and get access yourself, without asking a salesperson or an admin.
  • Gated — access needs a paid plan, an admin's approval, or a partner/sales deal.
  • Toolkit — Composio's ready-made set of actions for one app (for example “create an issue” or “send a message”).

    How it was done

    Four simple steps. No jargon needed.

    1. Find the docs. For each of the 100 apps, the agent searched for login rules, pricing, and whether an AI plug (MCP) already exists — and saved the pages it found.
    2. Answer the same questions. From those pages only, it filled one form per app: how you sign in, whether access is free, what the API covers, and whether a toolkit could be built today. If the page was unclear, it said “unknown” instead of guessing.
    3. Check the answers. Citations were auto-checked on all 100. A second pass re-answered the risky ones. Hard cases were opened in a real browser. A human then marked 15 apps right or wrong.
    4. Show the results here. Patterns, the full table, and this page are generated from the final data — one command rebuilds everything, offline, with no API keys.

    Where a human was needed: picking the 15-app audit sample, reading live pages for ~12 tricky apps, and fixing confirmed mistakes. Everything else was automated.

    Every claim had to cite a page

python run.py

    What this is not

    • Not a trial of every app. No paid accounts were created. Access answers come from public docs and pricing pages, checked by a human on a sample.
    • “Unknown” is a real answer. The agent was told to say it instead of guessing. Every unresolved field is visible in the table.
    • Pricing and plans change. Each row links to the pages used, so a reviewer can re-check quickly.
    • The human check is a sample (15 apps), not all 100. The page reports exactly what was checked and what was missed.
