The
Bright Data MCP server
gives AI agents and assistants real-time access to public web data through the Model Context Protocol (MCP). Connect it to Claude, Cursor or any MCP-compatible client, and your agent can search, scrape and read live web pages without you building or maintaining data pipelines.
Search runs on the SERP API and page scraping on the
Fetch API
, so you never manage proxies or anti-bot handling yourself. Every new account includes 5,000 free requests per month. You can run the server two ways: a fully managed remote server, or a self-hosted local instance.
