HighLevel API Documentation
Modified on: Mon, 16 Nov, 2026 at  5:49 AM
HighLevel provides APIs that allow developers to build custom integrations, automate processes, and connect external applications with the HighLevel platform.
The APIs support contacts, conversations, calendars, workflows, payments, webhooks, and more.
API access is available across HighLevel subscription plans. However, certain endpoints and capabilities may require a higher-tier plan.
Important:
API V1 reached end-of-support on December 31, 2025. Existing integrations may continue working, but API V1 no longer receives updates or technical support. Developers are encouraged to use supported API versions.
For complete endpoint references, visit the
Official HighLevel API Documentation
.
HighLevel API Documentation
The official API documentation provides information about available endpoints, authentication, request parameters, response formats, and supported API versions. Developers can use this documentation to:
Explore available API endpoints.
Review authentication requirements.
Check supported API versions.
Build and maintain custom integrations.
Understand endpoint-specific restrictions.
Note:
New legacy API key generation is being phased out. Private Integration Tokens and OAuth 2.0 are the recommended authentication methods.
How to Use Versioned API Documentation
Versioned API documentation allows developers to reference the correct API version when building or maintaining integrations.
Open the
HighLevel API Documentation
.
Select the required API version using the version switcher.
Review the available endpoints, parameters, and response formats.
Use the appropriate version when developing or updating integrations.
API V3 is available for supported endpoints. Availability varies by endpoint.

API Access Across HighLevel Plans
HighLevel offers API access across its subscription plans, including Starter, Unlimited, and Founder.
Both OAuth 2.0 and Private Integration Tokens (PIT) are available across plans. However, access to specific API endpoints depends on subscription eligibility, permissions, and scopes.

API Authentication Methods
HighLevel supports two primary authentication methods for modern API integrations.
Private Integration Tokens (PIT)
Private Integration Tokens allow developers to securely connect internal applications to HighLevel. They are suitable for account-specific integrations and allow permissions to be managed through assigned scopes.
OAuth 2.0
OAuth 2.0 allows applications to request authorized access to HighLevel accounts. It is commonly used for public integrations, Marketplace applications, and applications requiring user authorization.
Note:
The availability of an authentication method does not guarantee access to every API endpoint.
For setup instructions, see
Private Integrations: Everything You Need to Know

Frequently Asked Questions
Q: Is API access available on all HighLevel plans?
Yes. HighLevel provides API access across Starter ($97/month), Unlimited ($297/month), and Founder ($497/month) plans. OAuth 2.0 and Private Integration Tokens (PIT) are available across all plans. However, access to specific API endpoints depends on subscription eligibility, required scopes, and permissions. The Founder Plan, formerly Agency Pro, includes higher-tier API capabilities and access to eligible restricted endpoints.
For current subscription details, refer to
HighLevel Pricing
.
Q: Are OAuth 2.0 and Private Integration Tokens available on the Starter plan?
Yes. Both authentication methods are available across plans. Access to specific endpoints depends on permissions, scopes, and plan eligibility.
Q: What is the difference between Basic and Advanced API Access?
These terms describe API capabilities associated with subscription tiers. The specific endpoints available depend on the plan and endpoint-level restrictions.
Q: Does the Founder plan provide access to all API endpoints?
Not necessarily. Endpoint availability depends on the applicable subscription entitlements, scopes, and API-specific requirements.
Q: Is API V1 still supported?
No. API V1 reached end-of-support on December 31, 2025. Existing integrations may continue functioning, but updates and technical support are no longer provided.
Q: What authentication methods are supported?
HighLevel supports Private Integration Tokens and OAuth 2.0 for modern API integrations.
Q: Is API V3 available?
Yes. API V3 is available for supported endpoints. Developers should review the API documentation for version-specific availability.
