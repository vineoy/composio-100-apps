Default MCP Server
DealCloud provides a default MCP Server out-of-the-box without any configuration required. It exposes your site's full schema and is the fastest way to get connected. Copy the MCP endpoint URL from
Tools > MCP Servers
and connect it to your AI client. The default endpoint follows this format:
https://[tenant].my.intapp.com/mcp/celeste/DealCloud
Custom MCP Servers
Need to scope data access by team, workflow, or AI client? Custom MCP Servers let you control exactly what each client can see by pairing a server with a Schema Contract. See
Custom MCP Servers
for setup details.
Enabling Write Tools
To let assistants create and update records, go to
Tools > MCP Servers
, edit the MCP Server, and turn on the
Enable Write Tools
toggle. See
MCP Tools
for the full list.
