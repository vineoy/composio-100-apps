The endpoint creaters an access token which is required to authorize requests to all other endpoints

REQUEST PARAMETERS
client_id
The
client_id
is the
Client ID
from the OtterSign app under
Settings
→
Account and Preferences
→
API keys
. See
Account setup
for screenshots and a direct link.
client_secret
The
client_secret
is the
Client Secret
in the same
API keys
section. Use
Show
to reveal it, then
Copy
if needed.
grant_type
This parameter has a constant value of
client_credentials
scope
This parameter has constant scope value of
api
RESPONSE PARAMETERS
account
This
response object
contains all information about the authenticated user
token
The token value
MUST
be part of the header parameters for all other requests sent to all other endpoints.
The token value is assigned to the
Authorization
parameter of the header.
Example:
Authorizaton: Bearer ${token}
refreshToken
This parameter is used to refresh the generated token value.
