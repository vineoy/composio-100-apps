Where Can I Find the LiveAgent API Documentation?
Customer context:
The customer is looking for information on where to access the API documentation for LiveAgent.
Customer question:
Where can I find the LiveAgent API Documentation?
Solution:
You can access the complete LiveAgent APIv1 documentation at the following link:
https://support.liveagent.com/840770-Complete-API-reference
. For APIv3 documentation, please log in to your LiveAgent panel and navigate to Configuration > System > API > APIv3 documentation, where you can view the latest APIv3 reference directly.
