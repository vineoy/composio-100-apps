## Authentication

Every request requires a Bearer token in the `Authorization` header. Keys start with `ipx_live_`.

HTTP

`Authorization: Bearer ipx_live_xxxxxxxxxxxx`

## /audit

Run a forensic audit on a single transaction. Returns a 0–10 score, hidden spread vs mid-market, and estimated loss.

bash

```
curl -X POST https://hvujzsdwcoweirroubeh.supabase.co/functions/v1/fx-public-api-v1/audit \
  -H "Authorization: Bearer ipx_live_YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "amount": 50000,
    "currency_from": "USD",
    "currency_to": "EUR",
    "bank_rate": 0.91
  }'
```

## /rates

Live mid-market rates from Twelve Data. Pass `base` (default USD) and optionally `quote` for a single pair.

bash

```
curl "https://hvujzsdwcoweirroubeh.supabase.co/functions/v1/fx-public-api-v1/rates?base=USD&quote=EUR" \
  -H "Authorization: Bearer ipx_live_YOUR_KEY"
```

POST

## /audit/document

Audit a batch of parsed transactions (e.g. exported from QuickBooks, Xero, Sage, or your CSV). Returns weighted-average spread and per-row breakdown.

bash

```
curl -X POST https://hvujzsdwcoweirroubeh.supabase.co/functions/v1/fx-public-api-v1/audit/document \
  -H "Authorization: Bearer ipx_live_YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "rows": [
      {
        "date": "2026-04-15",
        "sourceCurrency": "USD",
        "targetCurrency": "EUR",
        "amountSource": 10000,
        "amountTarget": 9050
      }
    ]
  }'
```

## Webhooks

Subscribe to `audit.completed` events to power Zapier triggers, n8n workflows, or your own Slack alerts. Every payload is signed with HMAC-SHA256.

### Verifying signatures (Node.js)

javascript

```
import crypto from "node:crypto";

function verifySignature(rawBody, signature, secret) {
  const expected = "sha256=" + crypto
    .createHmac("sha256", secret)
    .update(rawBody)
    .digest("hex");
  return crypto.timingSafeEqual(
    Buffer.from(signature),
    Buffer.from(expected),
  );
}

// In your Express/Next.js handler:
app.post("/webhook", express.raw({ type: "application/json" }), (req, res) => {
  const sig = req.headers["x-ipayx-signature"];
  if (!verifySignature(req.body, sig, process.env.IPAYX_WEBHOOK_SECRET)) {
    return res.status(401).send("invalid signature");
  }
  const event = JSON.parse(req.body);
  console.log("Audit completed:", event.data);
  res.status(200).send("ok");
});
```
