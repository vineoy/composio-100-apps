Skip to main content
If you already use ChatGPT, Claude, or Microsoft 365 Copilot, connect Consensus to it. Your assistant can then search over 400 million scholarly articles, including 350 million peer-reviewed research papers, apply academic filters, hand research questions to the Consensus research agent, and cite real research instead of answering from memory.

Connect another tool
Using a different assistant or tool, such as Cursor, VS Code, or Claude Code? Connect it to the Consensus MCP server directly. MCP (Model Context Protocol) is a standard way for AI assistants to use outside tools. The server is hosted, so there’s nothing to install:
https://mcp.consensus.app/mcp

What your assistant can do
Search.
The
search
tool returns ranked papers with title, authors, journal, publication year, citation count, study type, a key takeaway, and a link to the paper on Consensus. On paid plans it also returns query-relevant excerpts from open-access papers, so your assistant can quote the passage behind each claim. Your assistant can pass the same filters Research Agent uses:
Year range, study type, and journal quartile (SJR)
Human and controlled studies, minimum sample size, minimum citations
Medical mode, open access only, exclude preprints
Study duration and country
Read whole papers.
On paid plans,
get_full_text
reads the complete text of open-access papers from search results or Threads, so your assistant can work from a paper’s methods and results, not just its abstract.
Threads.
With a signed-in account, your assistant can also run
Research Agent
as a Thread.
create_thread
starts the agent on a research question,
get_thread
returns the cited answer when it’s ready,
add_to_thread
asks a follow-up, and
find_threads
finds earlier Threads. The agent can search your Library collections and save papers to them, and
deep
mode runs a longer literature review on paid plans.

Use the API
Building your own tool, agent, or workflow? The Consensus API gives you the same paper search over REST, and can run Research Agent as a Thread. Send a query, get back ranked peer-reviewed papers with metadata, and skip running each search by hand. It’s self-serve and open to everyone.
GET https://api.consensus.app/v1/search
The top 20 most relevant papers per query by default; raise
page_size
for more, up to your plan’s maximum
Metadata on every paper: title, authors, journal, year, DOI, citation count, and a link
On paid plans: study design, journal rank, key takeaways, and query-relevant excerpts from open-access papers
The same filters as the web app: publication date, study type, sample size, citations, journal quality, field, country, and open access
