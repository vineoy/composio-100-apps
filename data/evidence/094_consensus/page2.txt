The Consensus API lets you search 400+ million scholarly articles, including 350 million peer-reviewed research papers, over a single REST endpoint. Send a query and get back ranked papers with titles, authors, journals, publication years, citation counts, and direct links.
Quickstart
Make your first API call in a few minutes. Every plan includes API access, and the Free plan includes 30 calls a month.
1
Sign in to Consensus
Create a free account or sign in at
consensus.app
. The dashboard in the next step only opens when you’re signed in.
2
Open the API & MCP Dashboard
Go to
consensus.app/api-mcp
. You can also get there from your profile icon: choose
API & MCP Dashboard
.
3
Create and copy an API key
Click
Create API key
, name the key, and click
Copy API key
. The full key is shown only once, so store it somewhere safe.
Already have a key? Open
Keys and clients
and click
New key
.
4
Make your first request
Save the key in an environment variable named
CONSENSUS_API_KEY
:
export
CONSENSUS_API_KEY
=
"paste-your-key-here"
Then search.
query
is the only required parameter, and the key goes in the
x-api-key
header.

How Consensus compares
In blinded evaluations on real user queries, Consensus search returns more relevant papers than Google Scholar and than frontier models with web search. See
Benchmarks
.
More relevant than Google Scholar
88.1% vs 81.8% precision on 500 real user queries, judged blind by PhD researchers.
Beats GPT-5.5 and Opus 4.8, 10x faster
More relevant top-20 papers at a median of 8.7 seconds, versus 75 to 103 seconds.
What people build with the API
What you can build with the Consensus API
Teams use the API to power internal research tools, field-monitoring agents, and scientific agents. Phylo calls it directly from its agents to screen about 20,000 drug targets across hundreds of diseases. Browse the use cases.
Internal tools:
paper search for scientific agents, field-monitoring agents, and literature tables that fill themselves.
Research systems:
literature review pipelines, citation-grounded writing, and recurring evidence reports.
Full text in the API
Every search reaches inside the paper. Queries are matched against full text where available, and on paid plans each open-access result also carries the passages that answer your query, in
full_text_chunks
. To read a whole open-access paper, pass its
paper_id
to
GET /v1/papers/full_text
for its complete text as Markdown.
