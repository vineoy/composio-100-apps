Overview of the Squarespace MCP Server
The Squarespace MCP server connects AI assistants to Squarespace. It's built on the
Model Context Protocol
, an open standard for connecting AI applications to outside tools, so assistants like Gemini, Claude, and ChatGPT can look things up and make changes on Squarespace in the middle of a conversation.
With it, someone can describe a new business and leave the chat with a domain ready to buy, or ask "which orders still need shipping?" about their own store and get a live answer.

How it works
The Squarespace MCP server is a remote server. There's nothing to install. Your MCP client connects directly to:
Code
https://mcp.squarespace.com/mcp
You don't call the tools yourself. You ask the assistant for something in plain language, and it decides which tools to call and in what order. The tool descriptions the assistant needs are sent by the server when it connects, so they don't need to be copied into your prompts.
Signing in
The Domains tools work for anyone, with no Squarespace account required.
The Commerce tools read and change a website, so they need you to sign in with your Squarespace account. They only appear in your client once you've signed in, and they act with your own permissions: an assistant can only see and change what you could see and change yourself in that website's Commerce panel. See
Connect a Client
.
Working with a website
Every signed-in tool works on one website at a time. If it isn't clear which site you mean, the assistant will ask, then keep using that site for the rest of the conversation until you ask to switch.
What the tools can and can't change
Domains tools never buy anything.
They return a checkout link. A domain is only registered when someone opens that link and completes checkout on squarespace.com.
Commerce tools don't move money.
They can create and update contacts and products, but they can't take payments, issue refunds, or fulfill orders. Orders are read-only.
Changes are real.
A product or contact the assistant creates or edits is saved to your live website. New products are hidden from shoppers until you (or the assistant, if you ask) publish them.
Most MCP clients ask you to approve a tool before it makes a change. Keep that approval step turned on for tools that write to your website.
Supported clients
Squarespace is built into Gemini as a connected app, and the Domains tools also work in Claude, ChatGPT, and any client that supports remote MCP servers. The Commerce tools are currently only available in Claude and ChatGPT. See
Connect a Client
for setup steps.
