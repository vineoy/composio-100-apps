Notion

Other MCP clients
Add Notion as a remote MCP server with the Streamable HTTP transport and the URL
https://mcp.notion.com/mcp
.
Migrate from the legacy SSE endpoint
Notion will retire the legacy HTTP with Server-Sent Events (SSE) endpoint,
https://mcp.notion.com/sse
, on
February 23, 2027
. Update your client before that date.
In your client’s Notion server settings, change the transport from SSE to Streamable HTTP and replace the URL with
https://mcp.notion.com/mcp
. Save the settings, sign in again if prompted, and check that the client lists Notion tools. If your client only offers SSE, update it to a version that supports Streamable HTTP.

FAQs
Can I use Notion MCP without interactive authorization?
Yes, on Business and Enterprise plans. A workspace owner can create an MCP token with
New MCP token
in the Developer portal. The MCP client sends the token as a bearer token to
https://mcp.notion.com/mcp
, with no browser sign-in.
Enterprise workspaces that use SAML SSO can also use
enterprise-managed authorization
, where the company’s identity provider grants access without a consent screen.
Which Notion plans can use Notion MCP?
Notion MCP works on every plan. Some features depend on the workspace’s plan:
MCP tokens
: Business and Enterprise. Only workspace owners can create them.
Enterprise-managed authorization
: Enterprise, with SAML SSO.
Connected-source search
with
notion-connector-search
: Business or Enterprise with Notion AI.
notion-search
searches Notion on every plan.
Database queries
with
notion-query-data-sources
: querying a saved view works on every plan. SQL queries are unlimited on Business or Enterprise with Notion AI. Other plans get a limited number of SQL queries on one data source at a time.
Some search filters
, such as last edited by and last edited date: Business and Enterprise. On other plans these filters are dropped, and the result says so.
Request limits
: higher on Business and Enterprise. See
rate limits
.
Can workspace guests use Notion MCP?
No. Only workspace members can connect Notion MCP. A guest who tries to connect sees a message that guests can’t connect, and Notion refuses the authorization.
Does Notion MCP support file uploads?
Yes. Use the
notion-create-file-upload
tool
to upload images and other files up to 20 MiB. Workspace file-size limits still apply.
The tool returns a short-lived upload URL and the headers and form field that the MCP client must use to send the file. After the upload succeeds, pass the response’s
suggested_markdown
directly to
notion-create-pages
or
notion-update-page
, or include it on a separate line in
notion-create-comment
markdown to attach the file. For larger files, use the
file upload API
.
What's the difference between Notion MCP and the open-source server?
Notion MCP
(
https://mcp.notion.com/mcp
) is our hosted, actively maintained server. It supports OAuth authorization and MCP tokens, and requires no infrastructure setup.
The
open-source server
(
notion-mcp-server
) is no longer actively maintained. It authenticates with an integration token and requires you to manage your own connection and deployment.
For most users, we recommend Notion MCP.
