Authentication guide
The Payout API supports JWT and x-signature as the primary authentication mechanism. In order to make requests to our system, you will need to authenticate them. To do that, you need to include the following fields in the headers of all API requests:
Content-Type
X-API-Key
Authorization
x-signature
The description of these parameters is provided in the table below:

Description
