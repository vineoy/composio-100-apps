Official Grain MCP Server
Announced:
June 18, 2025
Mike Adams
‍
Grain's official MCP server is available now for all users! 🎉
‍
With Grain's new MCP server you can securely access your meetings, notes, transcripts, deals, & coaching scorecard data natively using Anthropic's new Claude Integrations (ChatGPT coming soon), or using
mcp-remote
in Cursor, Windsurf and other clients.
‍
In addition to being able to ask any prompt in Cluade with Grain data, the server includes built-in MCP Prompts to run one-click reports like:
📣 Weekly "Voice of the Customer" reports to track sentiment & requests
📊 Pipeline IQ analysis to identify high opportunity & at-risk deals
🌶️ SPICED/MEDDICC reports to deeply understand a deal across meetings
🗣️ Sales Skill Scorecards to eval and track our team's performance over time
Check the demo and
quick-start guide
to get set up in less than 60 seconds.
Best,
Mike
