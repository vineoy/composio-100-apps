On this page
Pylon’s API can be used to programmatically access and take action on data within Pylon.
Only Admin users can create API tokens. To learn more about Admins, see
Roles & User Management
.
Some common use cases for our API include:
Fetching information about customers
Fetching information about issues
Creating issues programmatically
Check out our
API Reference
for specifications on all endpoints. To call the API from TypeScript, Python, or Go, use our
SDKs
, with pinned installation commands and upgrade guidance for each language.
Prefer the terminal? Try our experimental
Pylon CLI
. It’s an early release and may change.
Before you build an integration, read:
Authentication
for creating tokens, roles, and regions
API conventions
for IDs, timestamps, pagination, search filters, update behavior, files, and slugs
Rate limits
for request limits and how to handle
429
responses
Errors
for error codes and response format
