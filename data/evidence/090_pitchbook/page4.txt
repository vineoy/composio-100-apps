Help: Getting started with PitchBook’s Premium Connector
This article covers PitchBook Premium Connector, including the functionality and the partner platforms it supports.
Overview
As we rely on AI tools to move faster and make smarter decisions, switching between tools to find data can be time-consuming. PitchBook’s Premium Connector solves this by integrating PitchBook data directly into the AI platforms you already use. With secure access, you can query private market insights without disrupting workflow. In this article, learn how our Premium Connector works and which AI platforms we partner with.
How it works
The Premium Connector provides a secure link between PitchBook and AI tools. Once connected, you can use your AI tool to access a wide range of PitchBook’s private market data directly. By specifying
“
Using PitchBook data as the source
”
in your query, you ensure the response includes only PitchBook’s verified proprietary data.
When a question is sent, the connector translates it into a query that PitchBook can process. It then retrieves the relevant information, formats it, and sends it back to the AI tool. This workflow ensures that data is delivered accurately and only according to the permissions assigned to each user.
Workflow
This section outlines the general workflow for using the Premium Connector. While setup may vary slightly across different AI partners, the core process follows these steps:
Setup
– AI partners connect securely to PitchBook’s Premium Connector (built on MCP server technology) directly through the partner’s site. There’s no need for local installation or custom integration as the connection is managed in the cloud, allowing quick deployment.
Authenticate via SSO
– Only licensed PitchBook users can access the connector. Authentication happens through single sign-on (SSO), ensuring that access is secure and tied to each user’s permissions. Additional application-level safeguards ensure that only approved AI platforms, such as authorized enterprise accounts, can interact with PitchBook data. For instructions on enabling SSO, see
Getting started with single sign-on (SSO)
.
Use
–
Once connected, you can query PitchBook data directly within their AI tool. Common use cases include company research, deal sourcing, fundraising analysis, and benchmarking comparable companies.
