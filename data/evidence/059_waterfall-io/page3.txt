MCP tools reference
Every tool the hosted WP Waterfall MCP server offers, by toolset: what it does, the key scope it needs, and whether it asks you first.
{/* This page is generated from the tool registry. Do not edit it by hand. Run
pnpm gen:mcp-tools
. */}
The hosted server offers 331 tools. Your role decides which of them your assistant sees, and the API checks your role and your sites again on every call. See
Tools and guardrails
for the rules that apply to all of them.
The tools are grouped in toolsets, and a connection starts with every set on. To load fewer tools, add
?toolsets=
to the server address, for example
https://mcp.wpwaterfall.com/?toolsets=sites,webhooks
, or
?toolsets=compact
for the short list the server offered before every set became the default. The
core
toolset is always on, and the assistant can call
enable_toolset
to turn a set on or off during a session. A tool outside the sets that are on is refused if it is called.
Asks first
means the tool works in two steps. The first call changes nothing and says what would happen. Your assistant asks you in the chat, and only if you say yes does it call again with
confirm
set to true.
