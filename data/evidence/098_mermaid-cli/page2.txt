What is Mermaid API, and how is it different from Mermaid?
Mermaid is the open-source language and library that turns text into diagrams. Mermaid API is a hosted service that runs Mermaid for you: your program sends diagram code over HTTP and gets back a validation result, an image, or new diagram code.
Do I need a Mermaid subscription?
No. Any Mermaid account works, including a free one, and every account gets a monthly allowance of API credits. Paid plans include a bigger allowance.
How does pricing work?
Costs depend on the operation and options; stored-diagram reads are free. Your monthly allowance is spent first, then any credits you have bought. See the current costs in
api.mermaid.ai/v1/docs
; the free balance endpoint also returns your balance and endpoint costs. For high volume, contact sales.
Which diagram types and output formats are supported?
Every diagram type Mermaid supports (
see the docs
). Images come as SVG, PNG or PDF.
What happens to my diagram code?
Validate, render, generate and repair do not save a diagram in Mermaid Chart. Create and update explicitly persist diagrams in Mermaid Chart; Mermaid API keeps no copy of the diagram code. Rendered images are cached for up to a day, and you can turn caching off per request. Usage records hold counts and sizes, never your diagrams.
Who can access and share stored diagrams?
Use a personal key: it can read, overwrite and share diagrams according to its owner's existing Mermaid Chart permissions, including team projects. Organisation keys cannot use stored-diagram operations. Trust key holders with that access and revoke keys you no longer trust. An editUrl opens the editor; it does not grant access. Edit URL access follows existing permissions; a share link invites a recipient to View, Comment or Edit. Each share request returns a new shareUrl. Recipients must log in; invitations default to View, last 30 days and are not revocable before use. You cannot grant more access than the key owner has. See
api.mermaid.ai/v1/docs
for the full contract.
Can I pin a Mermaid version?
Yes. Each call can name the Mermaid version it should use, so your output stays the same until you choose to upgrade.
Is it production-ready?
Mermaid API is in open beta. You can build on it; breaking changes are announced in advance in the changelog, and there is no uptime guarantee yet.
