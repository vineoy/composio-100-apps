Meet the Pinterest MCP
The common language of AI and APIs
Model Context Protocol (MCP) is an open standard that enables AI assistants to connect directly with external services. The Pinterest MCP Server brings Pinterest data into the AI tools you already use, giving agents native access to rich inspiration and creative signals — without custom code or fragile integrations. It helps teams move from idea to on-brand creative direction with Pinterest intelligence available right where they work.
Built for Pinterest workflows
Bring Pinterest Ads capabilities into the AI tools your team already uses. Query, analyze, and act through a consistent interface powered by the existing Pinterest API.
Open-standard integration
Built on MCP, with compatibility across tools such as Claude, Cursor, and VS Code.
Secure, scoped access
OAuth 2.0 authorization and granular permissions keep credentials protected and access appropriately controlled.
Less integration work
Skip custom API wrappers. The MCP server manages authentication, rate limits, and response formatting, so teams can move faster.
