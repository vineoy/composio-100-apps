Page Summary
outlined_flag
The Google Ads API has access levels tied to the developer token and requires an application review to grant them.
Start with Basic Access and apply for Standard Access as your application grows, allowing for the potential review time.
The Required Minimum Functionality (RMF) only applies to developer tokens with Standard Access, so review these requirements beforehand.
The Google Ads API is free to use, but non-compliance with RMF for Standard Access users may result in fees.
The Google Ads API has
access levels
associated with the Google Cloud
project, and uses an application review process to grant various access levels.
It's important to plan and obtain the correct access levels before
productionizing your application.
A common scenario is that your application development starts with
Explorer
access level
, but then outgrows its quota limits over time. At
that point, you should apply for
Basic access level
or
Standard
access level
. While Basic access applications are reviewed
automatically, the Standard access review process can take several business days
or sometimes weeks to complete, so request your Standard access level upgrade
well before you need the increased quota limits.
Google may require that your app provide certain capabilities or features as
listed in the
Required Minimum Functionality (RMF)
. When using the
Google Ads API, the RMF only applies to Google Cloud projects with Standard access
level. Make sure you review these requirements in advance to avoid additional
delays around building the necessary features in your app.
Pricing
The Google Ads API is free to use; there are no charges for using the Google Ads API at
Explorer access, Basic access, or Standard access levels. However, if you are
subject to
Required Minimum Functionality (RMF)
, the API Review Team
audits your tool for compliance. If the audit results in a finding of
non-compliance, you may be required to pay
non-compliance fees
.
