We're excited to announce the release of the new Shopify.dev MCP Server! The MCP server gives your AI assistant access to Shopify's development resources, enabling it to search our docs, introspect API schemas, and get up-to-date answers about Shopify APIs. Now you can harness the full potential of the dev assistant directly within Cursor or Claude desktop.

Shopify dev MCP
server and take it for a spin!
